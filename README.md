# Портфолио Полины Шевченко

Сайт-портфолио веб-разработчика: сайты и лендинги под ключ, интернет-магазины и Telegram-боты.

**Живой сайт:** _ссылка появится после деплоя_

![Превью сайта](docs/preview.png)

## Стек

- [Next.js](https://nextjs.org) 16 — App Router, статический экспорт
- TypeScript
- [Tailwind CSS](https://tailwindcss.com) 4
- [Lenis](https://lenis.darkroom.engineering) — плавная прокрутка

## Что есть на сайте

**Секции:** шапка · hero с фото · обо мне · работы · услуги и стоимость · этапы работы · контакты

**Анимации и интерактив:**

- заголовки секций выезжают построчно из-под маски
- подпись на фото в hero дописывается при загрузке
- магнитная кнопка «обсудить проект»
- навыки «кучей» — плашки падают сверху с отскоком
- цифры в «Обо мне» набегают от нуля
- в карточках работ сайт прокручивается внутри экрана ноутбука при наведении
- вишнёвое свечение за курсором в карточках услуг
- бегущая строка ускоряется при скролле и разворачивается при прокрутке вверх
- линия этапов заполняется по мере прокрутки, номера загораются по очереди
- плёночное зерно поверх страницы, пиксельный курсор-рука
- ссылки на Telegram сначала открывают приложение, рядом кнопка «скопировать ник»

Если в системе включено «уменьшить движение», анимации отключаются.

## Как запустить локально

Нужен [Node.js](https://nodejs.org) 20 или новее.

```bash
npm install      # установить зависимости
npm run dev      # запустить сайт на http://localhost:3000
```

Другие команды:

```bash
npm run build    # собрать сайт — готовые файлы появятся в папке out/
npm run lint     # проверить код линтером
node scripts/mockups.mjs   # переснять сайты из портфолио и собрать мокапы
```

## Что где лежит

```
app/
  page.tsx              порядок секций на странице
  layout.tsx            шрифты, заголовок и описание сайта (SEO)
  globals.css           цвета, шрифты, анимации
  opengraph-image.tsx   картинка-превью для ссылок в мессенджерах
  icon.svg, apple-icon.png   значки сайта
components/             секции и элементы сайта — по файлу на каждый
  Hero.tsx, About.tsx, Works.tsx, Services.tsx, Process.tsx, Contacts.tsx …
data/
  site.ts               ← ВСЕ ТЕКСТЫ И ДАННЫЕ: работы, услуги и цены,
                          этапы, навыки, факты, контакты
public/
  photo.jpg             фото в hero
  works/                мокапы и скриншоты работ для карточек
  cursors/              пиксельный курсор
lib/                    вспомогательный код (Telegram, анимации, месяц в плашке)
scripts/mockups.mjs     генератор мокапов для карточек работ
assets/fonts/           шрифты для картинки-превью
```

**Частые правки:**

- добавить работу, поменять услугу или цену — `data/site.ts`
- поменять цвета — блок `@theme` в начале `app/globals.css`
- поменять порядок секций или убрать секцию — `app/page.tsx`
- координаты плашек навыков — массив `SPOTS` в `components/SkillPile.tsx`
